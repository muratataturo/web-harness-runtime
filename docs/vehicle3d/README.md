# 写真からの3D精度改善を実行した結果

## 画像の一致を主指標にした再検査

[参照画像・実レンダー・差分・重ね合わせを並べて見る](image-audit.html)。このモデルは元画像を綺麗に再現できていません。輪郭の一致ではなく、実際のBlender出力のRGB値でPSNRとSSIMを測りました。

| 比較対象・領域                                                    | PSNR     | SSIM  |
| ----------------------------------------------------------------- | -------- | ----- |
| 元の240×180画像への一致（カメラ枠を合わせた別枠のターゲット評価） | 11.72 dB | 0.327 |
| 未使用12方向・車体の固定ROI                                       | 12.02 dB | 0.452 |
| 同じ12方向・白背景を含む全画面                                    | 17.07 dB | 0.840 |
| 未使用12方向・最悪の視点                                          | 10.30 dB | 0.303 |

PSNRは全視点のMSEを画素数でプールして算出し、SSIMは視点ごとの平均を併記します。最悪値は各指標の最小値で、同じ視点とは限りません。主評価領域は参照車体の外接枠＋2.5%の余白を参照画像だけから固定します。前景の共通部分だけに限定せず、欠落した車体も誤差として残します。SSIMにはGaussian窓、data_range=1、sRGB値を使用。無断の位置合わせ・色補正や画像ワープはレンダー後に行いません。

元画像の正確なカメラは不明なため、近い公式ビューを選び、元画像の車体枠でカメラの枠合わせをした値です。この行は独立テストとは分けます。12方向の最終テストは復元・候補選択に不使用で、カメラ枠も復元用視点から補間しています。Blenderの実メッシュ頂点の投影と指定投影の差が0.01px以下であること、元モデルと出力PNGのSHA-256も検証します。

[全画像指標](image-metrics.json)と[39枚の実レンダーの検査記録](image-render-checks.json)を保存しています。旧モデル・前回提示したモデル・照明を外した診断の各13枚です。照明なし診断を完成モデルの品質値へ置き換えません。普遍的な規格ではありませんが、この試作では車体ROIと元画像の両方にPSNR≥20 dBかつSSIM≥0.8を要求し、未達なら `deliverable_accepted=false`・`image-match-failed`・終了コード2とします。

旧方式の約14.1 dBは、三角形の平均色の簡易描画を前景共通領域だけで比較した診断値です。完成画像の一致判定には不十分なため、参考値へ降格しました。以前の輪郭IoUの改善と、下記の当初の実証記録は補助資料です。

[実際の比較・回せる3D・採否ログを開く](index.html)。ローカルのブラウザで開ける自己完結HTMLです。表示用メッシュは粗い格子で軽量化し、実際の高解像度モデルは実行先の `.runtime/vehicle3d/<run>/` に保存します。

2026-11-18には、ユーザー指定の240×180画像を `gpt-6.2-astra` に渡し、生成コードをBlender 4.5.3で実行しました。93部品の外観モデル・概略三面図PDF/DXF・運動学的走行GIF・操舵と車輪回転を含むBlenderアニメーションを作成しました。寸法と背面・内部形状は仮定を含みます。その再現コードを `scripts/vehicle3d/` に整理しています。[前回の概略三面図PDF](prior-drawing.pdf)と[走行軌跡の縮小画像](prior-motion.jpg)も掲載します。[当初の生成入力](../../examples/vehicle3d/astra-generation-prompt.txt)も残しています。rawのモデル会話ログや大きなモデルは公開対象にしません。

今回の自律runtimeは、日産公式の諸元と360°ビューを追加取得し、手描き形状の微修正から、複数写真の輪郭による形状復元へ進めました。現行runtimeは数値処理とレビュー済みBlenderスクリプトを実行し、LLMは呼びません。`gpt-6.2-astra` の使用は前回の初期コード生成です。LLMが新しい測定値や見えない機構を確定したとは記録しません。

- [日産公式・主要諸元PDF](https://www-asia.nissan-cdn.net/content/dam/Nissan/jp/vehicles/kicks/2606/pdf/kicks_2606_specsheet_01_v1.pdf)、2ページ。日本仕様G e-4ORCEは全長4365・全幅1800・全高1610 mm、ホイールベース2655 mm。人が読んだ値を設定し、runtimeは取得物のハッシュを記録。諸元の意味を自動抽出・検証するエージェントではありません。

写真の枠合わせは推定アフィンカメラです。実カメラの透視投影やレンズ・歪みを較正していません。寸法の正規化と逆カメラ変換を同時に適用し、画像への投影を保っています。改善前モデルにも同じ座標変換を適用して、比較スコアが変わらないことを確認します。したがって、数値上の寸法一致は、実車と独立に一致を証明した測定ではありません。

より高精度な機械設計モデルに進むには、較正済みの追加撮影や実測点、OEM CADの入手と照合、公差・材質・可動軸の定義が必要です。これらがない状態で「近似ではなく正確」とは認定しません。

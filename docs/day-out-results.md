# 3ペルソナの一日遊び提案・実測

2026-11-10に実サイトと公式Codex CLI（0.167.0、ChatGPTログイン、gpt-6.1-sol）で3タスクを実行した。対象地が未指定だったため東京都内、対象日は2026-11-14（土）と仮定した。候補URLとペルソナを入力し、runtimeがページ取得・根拠保存・行程作成・追加調査を行った。施設や料理を架空データから生成する体験モードではない。予約・購入・問い合わせは行っていない。

入力は [day-out-personas.json](../examples/day-out-personas.json)。各実行の生の回答、候補評価、引用、取得URL、時刻、計測値は [記録JSON](evidence/day-out-results.json)。本文全文はローカルの各Task成果物へ保存する。

## 1. 20代カップル：浅草・押上で写真と水族館

大人2人、10〜19時、1人8,000円以内。下町の食事・水辺・写真が好き。

| 時刻 | runtimeが返した行程 |
| --- | --- |
| 10:00〜10:50 | 浅草駅集合、雷門周辺の写真散策 |
| 11:00〜12:00 | 雷門満留賀で昼食。かも南蛮1,650円（税込）を採用 |
| 12:10〜13:45 | 隅田川沿い散策、撮影しながら押上へ。移動45分は見積 |
| 14:00〜16:00 | すみだ水族館。大人2,700円。対象日の開館時刻が未取得なので仮時刻 |
| 16:15〜17:00 | カフェ休憩枠。具体店・席・価格は未確認 |
| 17:45〜19:00 | 夕食枠、押上駅で終了。具体店未確認 |

見積は **1人7,750円、2人15,500円**。掲載価格の昼食1,650＋入場2,700＝4,350円、未確認の予算枠は夕食2,000＋カフェ600＋交通800＝3,400円。土産や追加の買い食いは含まない。予算余裕は1人250円。

雨天は川沿い徒歩を電車と屋内休憩へ置き換える。楽しみの2択は「写真重視の徒歩（晴天時推奨）」／「移動を電車にして休憩を長く」。歩行・乗車時間や運賃は実測ではない。

[雷門満留賀公式](https://www.maruka.net/) / [すみだ水族館料金](https://sumida-aquarium.com/about/price/) / [営業時間・アクセス](https://sumida-aquarium.com/about/access/)。水族館の11/14当日営業時間が確認できず、追加調査後も `needs_input`。年中無休という通常条件から当日の入場を保証していない。

## 2. 大人2人＋5歳児：上野で動物、科学は任意

30代夫婦と5歳児、9:30〜17時、家族合計16,000円以内。徒歩移動を少なくし、休憩を2回入れる。

| 時刻 | runtimeが返した行程 |
| --- | --- |
| 9:30〜11:30 | 上野駅から動物園へ。好きな動物3種に絞る。10:30に休憩① |
| 11:55〜13:00 | まいかアトレ上野店で土日ランチ |
| 13:00〜13:30 | おやつ休憩②。疲れていたらここで終了 |
| 13:50〜14:50 | 元気があれば国立科学博物館の常設展を60分だけ追加 |
| 15:05頃〜17:00 | 上野駅へ。残りは移動・遅延の余白 |

推奨の動物園中心案は **家族合計9,820円**。動物園600円×大人2人＝1,200円、5歳児は無料。土日ランチ掲載の天婦羅御膳1,880円×2＋お子様プレート860円＝4,620円。交通2,500＋おやつ1,500は未確認の予算枠。

科博を追加すると大人630円×2＝1,260円を加え、**合計11,080円**。雨天に動物園を科博だけへ置き換えると9,880円の見積。子供本人が「動物をじっくり＋早帰り（推奨）」／「動物を少なめ＋博物館60分」を選ぶ。

[上野動物園公式料金・開園条件](https://www.tokyo-zoo.net/ueno/visitor-info/tickets/) / [科博入館案内](https://www.kahaku.go.jp/riyou/nyukan-annai/) / [まいか土日ランチ](https://www.hotpepper.jp/strJ001100102/lunch/)。科博の一部展示閉鎖も回答へ記載した。動物園の対象日PDFが取得できず臨時休園が未確認、土日ランチの提供終了時刻や制限時間も未確認で、追加調査後も `needs_input`。

## 3. 30代一人：浜離宮・築地・読書でリフレッシュ

会社員1人、10〜17時、6,000円以内。疲れているため、静かな庭園と休憩を重視する。

| 時刻 | runtimeが返した行程 |
| --- | --- |
| 10:00〜12:30 | 浜離宮で短い散策、池の観察、読書・休憩 |
| 12:30〜13:00 | 築地へ徒歩20〜30分の見積 |
| 13:00〜14:00 | 築地かに祭りで海鮮バラちらし1,600円（税込）の案 |
| 14:15〜16:30 | カフェ読書枠。具体店・席・長時間利用可否は未確認 |
| 17:00 | 築地駅方面で終了 |

見積は **4,900円**。掲載価格は庭園300＋昼食1,600＝1,900円。未確認予算枠のカフェ1,000＋交通1,000＋予備1,000を加算。昼食単品の土曜提供は確認できず、提供がなければ2,700円以内の昼食へ調整するという条件付き。

日本科学未来館は、公式の2026/10/1〜2027/4/22の全館休館告知を確認して候補から外した。雨天代替にも使わない。小雨なら庭園を短縮、強雨・強風なら庭園を中止して昼食・短い屋内休憩で早帰りする。楽しみの2択は「池の観察＋読書（推奨）」／「庭園ガイド参加（当日の実施保証なし）」。

[浜離宮公式案内](https://www.tokyo-park.or.jp/park/hama-rikyu/index.html) / [築地かに祭り](https://www.hotpepper.jp/strJ003410694/) / [未来館の休館告知](https://www.miraikan.jst.go.jp/visit/admission/)。初回の提案は保存済みだが、追加調査は120秒で中断され `timed_out`。保存済みの初回提案を保持した。土曜の単品提供、具体的なカフェ、静けさ・空席は未確認。

## レイテンシーとトークン量

最大2並列、初回は90ステップ/14ページ/240秒、自己改善は各1回・全体120秒まで。モデルは全件gpt-6.1-sol、実行エンジンはcodex。全体の壁時計時間は **509.209秒（約8分29秒）**。

合計観測値は入力1,431,385、出力17,646、合計 **1,449,031トークン以上**。キャッシュ入力1,144,320は入力の内数、推論出力19も出力の内数であり加算しない。Codexの `thread/tokenUsage/updated.tokenUsage.total` の最後に受信した累積値を使い、通知を重複加算せず、別threadの通知は除外する。入力はツール本文や会話履歴の繰り返し・キャッシュを含み、ユニークな文章量とは異なる。

※一人案の追加調査は中断された。583,041は受信できた累積値の合算で、停止直前の未通知分が含まれない可能性がある。`last-observed-partial` として、実際の全消費トークンを確定した値にはしない。他2件は通常終了した2回のモデル実行を合算した。

所要時間はrunTask開始から成果物保存・自己改善終了までの実測で、今回の計測機能の実装、候補URLの事前準備、実行許可の待機、検証作業、この会話の生成時間は含まない。初回値はTask内の後処理完了までの時間で、最終ファイル書込のごく短い時間は含まない。最終所要時間は外側のタイマーで成果物保存も含めて計測した。TTFTは測定していない。

## 実行結果の評価

- 時刻付き提案・予算・雨天代替・楽しみの2択は3件とも生成した。
- 全条件確認済みとして完了したケースは0件。2件はneeds_input、1件は追加調査がtimed_out。
- 自己改善3回で採用された改善は0回。今回は追加の取得が情報不足の解消につながっておらず、初回提案を保持した。再取得の効率とPDF/日付別カレンダーの取得に改善余地がある。
- 一方、未来館の全館休館を認識して除外、子供料金、土日ランチ、見積の交通/カフェ費用の分離、予算の加算は確認できた。利用者の実際の満足度を測ったものではない。
- 公式の施設案内を読むURL形式と取得契約を追加したが、今回の取得だけでtrusted台帳に新規URLを自動登録してはいない。

```sh
npm run build
npm run eval:day-out -- --agent codex --model gpt-6.1-sol --parallel 2
# 初回だけ測る場合
npm run eval:day-out -- --agent codex --model gpt-6.1-sol --no-improve
# 1ペルソナだけ
npm run eval:day-out -- --persona family-ueno --agent codex
```

CLIは全件成功0、要確認/部分結果2、失敗/未実行/追加調査の時間上限1、中断130を返す。quota・認証等の既知の停止条件は後続の未実行ペルソナを記録して停止する。

137テスト・型・ビルド・整形を確認。ネイティブトークンの累積値を通知回数で二重計上しないこと、別threadを除外すること、欠測を0にしないこと、施設URLと取得契約を検証する。今回のトークン計測はCodex対応で、Claude/piのトークン値は未実装ならnullになる。
